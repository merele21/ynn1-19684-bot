# 🤖 Telegram Forwarder Bot

Бот для автоматической пересылки сообщений из одной группы в другую по хештегам.

## 🎯 Возможности

- ✅ Пересылка сообщений по хештегам
- ✅ Удаление хештега при пересылке
- ✅ Поддержка FSM для выбора типа пересылки
- ✅ Задержка для сбора медиагрупп (10+ фото)
- ✅ Whitelist хештегов
- ✅ Команды для управления конфигурацией
- ✅ Получение ID группы и треда

## 📋 Требования

- Python 3.9+
- aiogram 3.4.1
- python-dotenv
- aiofiles

## 🚀 Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository_url>
cd telegram_forwarder_bot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте окружение:**
```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```env
BOT_TOKEN=ваш_токен_от_BotFather
SOURCE_CHAT_ID=-100123456789
ADMIN_IDS=123456789,987654321
```

4. **Настройте хештеги:**

Отредактируйте `config.json` (пример уже есть) или используйте команды бота.

## 🎮 Команды бота

### Административные команды

- `/start` - Запустить бота и увидеть список команд
- `/help` - Показать справку по командам
- `/add_hashtag #хештег -100123456789 123 delay=10` - Добавить новый хештег
- `/list_hashtags` - Показать все настроенные хештеги
- `/remove_hashtag #хештег` - Удалить хештег
- `/get_supergroup_id` - Получить ID группы (переслать сообщение из группы)
- `/get_thread_id` - Получить ID треда (переслать сообщение из топика)

### Примеры использования

**Добавление простого хештега:**
```
/add_hashtag #новости -1001234567890 123
```

**Добавление хештега с задержкой:**
```
/add_hashtag #фото -1001234567890 456 delay=15
```

**Получение ID группы:**
1. Отправьте команду `/get_supergroup_id`
2. Перешлите любое сообщение из нужной группы
3. Бот покажет ID группы и ID треда (если есть)

## 📝 Конфигурация хештегов

### Формат config.json

```json
{
  "hashtags": {
    "#закрытие": {
      "needs_fsm": true,
      "description": "Закрытие смены с выбором типа",
      "options": {
        "single": {
          "chat_id": -1001234567890,
          "thread_id": 123,
          "delay": 0
        },
        "mediagroup": {
          "chat_id": -1009876543210,
          "thread_id": 456,
          "delay": 15
        }
      }
    },
    "#новости": {
      "needs_fsm": false,
      "description": "Простой хештег без FSM",
      "chat_id": -1001234567890,
      "thread_id": 789,
      "delay": 0
    }
  }
}
```

### Параметры:

- **needs_fsm** (bool) - требуется ли выбор типа пересылки через FSM
- **description** (string) - описание хештега
- **chat_id** (int) - ID чата назначения (для хештегов без FSM)
- **thread_id** (int) - ID треда/топика
- **delay** (int) - задержка в секундах для сбора медиагрупп
- **options** (object) - варианты для хештегов с FSM

## 🔄 Как это работает

### 1. Простая пересылка (без FSM)

Пользователь отправляет в исходную группу:
```
#новости Важная новость!
```

Бот:
1. Обнаруживает хештег `#новости`
2. Удаляет хештег из текста
3. Пересылает "Важная новость!" в указанный тред

### 2. Пересылка с FSM

Пользователь отправляет:
```
#закрытие Смена закрыта
```

Бот:
1. Обнаруживает хештег с `needs_fsm: true`
2. Показывает кнопки выбора: "Одиночное фото" или "Медиагруппа"
3. После выбора пересылает в соответствующий чат/тред

### 3. Пересылка с задержкой (медиагруппы)

Когда у хештега установлен `delay > 0`:

1. Пользователь отправляет первое фото с хештегом
2. Бот ждёт указанное время (10-25 секунд)
3. Собирает все последующие сообщения без хештега
4. Пересылает все сообщения вместе

**Пример:**
```
Сообщение 1: #фото Альбом с 11 фотографиями
Сообщение 2: [фото без текста]
Сообщение 3: [фото без текста]
...
```

Бот соберёт все и перешлёт в один тред.

## 🔐 Безопасность

- Только администраторы могут использовать команды бота
- ID администраторов задаются в `.env` файле
- Whitelist хештегов защищает от случайных пересылок
- Бот работает только в указанной исходной группе
