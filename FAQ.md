# ❓ FAQ - Частые вопросы

## Общие вопросы

### Q: Как получить токен бота?

**A:** 
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям (укажите имя и username)
4. BotFather пришлёт токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
5. Скопируйте токен в `.env` файл

---

### Q: Как узнать мой Telegram ID?

**A:**
1. Найдите бота [@userinfobot](https://t.me/userinfobot)
2. Отправьте ему `/start`
3. Он пришлёт ваш ID (например: `123456789`)
4. Используйте этот ID в `ADMIN_IDS` в `.env` файле

---

### Q: Как получить ID группы?

**A:**
Два способа:

**Способ 1 (через бота):**
1. Запустите вашего бота
2. Отправьте команду `/get_supergroup_id`
3. Перешлите любое сообщение из нужной группы
4. Бот покажет ID группы

**Способ 2 (вручную):**
1. Добавьте бота [@getidsbot](https://t.me/getidsbot) в группу
2. Он автоматически покажет ID группы

---

### Q: Как получить ID треда (топика)?

**A:**
1. Отправьте боту команду `/get_thread_id`
2. Перешлите сообщение из конкретного треда
3. Бот покажет ID треда

**Важно:** Thread ID — это ID первого сообщения в треде!

---

## Настройка и конфигурация

### Q: Можно ли использовать несколько хештегов в одном сообщении?

**A:** Да, но бот обработает только первый найденный хештег. Если нужно пересылать в несколько мест, отправьте отдельные сообщения с разными хештегами.

---

### Q: Как изменить конфигурацию хештега?

**A:** 
Два способа:

**Способ 1 (через команды):**
```bash
/remove_hashtag #старый
/add_hashtag #новый -100123456 789
```

**Способ 2 (вручную):**
1. Откройте `config.json`
2. Измените нужные параметры
3. Перезапустите бота

---

### Q: Что такое FSM и когда его использовать?

**A:** FSM (Finite State Machine) — это механизм для хештегов, которым нужен выбор места пересылки. 

**Используйте FSM когда:**
- Один хештег должен пересылать в разные места
- Нужен выбор между "одиночное фото" и "медиагруппа"
- Требуется дополнительная логика перед пересылкой

**Пример:** `#закрытие` может отправлять либо в тред "Простые закрытия", либо в тред "Детальные отчёты" с множеством фото.

---

### Q: Как работает delay и зачем он нужен?

**A:** 
Delay (задержка) нужна для сбора медиагрупп с 11+ фотографиями.

**Проблема:** Telegram ограничивает текст при отправке 11+ фото в одной медиагруппе. Первые 10 фото идут с текстом, 11-е и далее — без текста.

**Решение:** 
- Устанавливаем delay=15
- Бот видит сообщение с хештегом
- Ждёт 15 секунд
- Собирает все последующие сообщения
- Пересылает их вместе

**Рекомендуемые значения:**
- 0 сек — для одиночных сообщений
- 10 сек — для 6-10 фото
- 15 сек — для 11-15 фото
- 20 сек — для 16+ фото

## Права и доступ

### Q: Какие права нужны боту в группах?

**A:**
- **В исходной группе (откуда пересылаем):** Администратор с правом чтения сообщений
- **В целевых группах (куда пересылаем):** Обычный пользователь (может отправлять сообщения)

---

### Q: Может ли бот работать в приватных группах?

**A:** Да! Бот работает в:
- Публичных группах
- Приватных группах
- Супергруппах
- Группах с тредами (Topics)

---

### Q: Как добавить ещё одного администратора бота?

**A:**
1. Откройте `.env` файл
2. Добавьте ID нового админа через запятую:
```env
ADMIN_IDS=123456789,987654321,111222333
```
3. Перезапустите бота

## Проблемы и ошибки

### Q: Бот не отвечает на команды

**A:**
Проверьте:
1. ✅ Бот запущен (`python bot.py`)
2. ✅ Ваш ID в списке `ADMIN_IDS`
3. ✅ Токен бота правильный
4. ✅ Интернет соединение работает

---

### Q: Бот не пересылает сообщения

**A:**
Проверьте:
1. ✅ Хештег добавлен в конфигурацию (`/list_hashtags`)
2. ✅ Сообщение отправлено в исходную группу (SOURCE_CHAT_ID)
3. ✅ Бот добавлен в целевую группу
4. ✅ chat_id и thread_id указаны правильно
5. ✅ Бот имеет права на отправку сообщений

---

### Q: Ошибка "Chat not found"

**A:**
Это значит, что бот не добавлен в целевую группу или ID указан неверно.

**Решение:**
1. Убедитесь, что бот добавлен в группу
2. Проверьте правильность chat_id (должен начинаться с `-100`)
3. Используйте команду `/get_supergroup_id` для проверки

---

### Q: Задержка (delay) не работает

**A:**
Возможные причины:

1. **Последующие фото содержат хештег** — удалите хештег из всех фото кроме первого
2. **Задержка слишком маленькая** — увеличьте delay до 15-20 секунд
3. **Между фото большие паузы** — отправляйте фото быстрее

---

### Q: FSM клавиатура не появляется

**A:**
Проверьте:
1. ✅ В `config.json` указано `"needs_fsm": true`
2. ✅ Секция `"options"` настроена правильно
3. ✅ Бот перезапущен после изменения конфигурации

---

## Продвинутые вопросы

### Q: Можно ли пересылать не только фото, но и документы?

**A:** В текущей версии бот поддерживает только фото и текст. Для поддержки документов нужно доработать код в `forwarding.py` (добавить обработку `message.document`).

---

### Q: Можно ли пересылать в несколько групп одновременно?

**A:** В текущей версии — нет. Один хештег = одна пара (chat_id + thread_id).

**Обходное решение:** Создайте несколько хештегов:
```
#новости1 → Группа 1, Тред 123
#новости2 → Группа 2, Тред 456
```

---

### Q: Как сделать резервное копирование конфигурации?

**A:**
```bash
# Создать резервную копию
cp config.json config.json.backup

# Восстановить из резервной копии
cp config.json.backup config.json
```

Рекомендуется делать backup перед большими изменениями!

---

### Q: Можно ли запустить бота на сервере?

**A:** Да! Используйте:

**Вариант 1: screen/tmux**
```bash
screen -S telegram-bot
python bot.py
# Нажмите Ctrl+A затем D для выхода
```

**Вариант 2: systemd service**
См. файл `USAGE_EXAMPLES.md` раздел "Deployment"

**Вариант 3: Docker**
```bash
docker build -t telegram-bot .
docker run -d telegram-bot
```

---

### Q: Бот потребляет много памяти

**A:** 
Бот хранит в памяти pending_forwards для обработки задержек. Если память — проблема:

1. Уменьшите значения delay
2. Очищайте pending_forwards периодически
3. Используйте Redis вместо MemoryStorage для FSM

---

### Q: Как добавить логирование в файл?

**A:**
Отредактируйте `bot.py`:

```python
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler("bot.log"),
        logging.StreamHandler()
    ]
)
```

---

### Q: Можно ли отредактировать уже пересланное сообщение?

**A:** Нет, текущая версия бота не поддерживает редактирование. Для этого нужно хранить message_id пересланных сообщений.

## Безопасность

### Q: Безопасно ли хранить токен в .env файле?

**A:** 
Да, если:
1. ✅ Файл `.env` в `.gitignore`
2. ✅ Права на файл: `chmod 600 .env`
3. ✅ Не публикуете `.env` в репозитории
4. ✅ Используете переменные окружения на проде

---

### Q: Может ли кто-то использовать бота без прав?

**A:** Нет! Все команды проверяют, что `user_id in ADMIN_IDS`. Без прав админа никто не сможет использовать бота.

---

### Q: Как защитить бота от спама?

**A:** 
В текущей версии бот работает только в одной исходной группе (SOURCE_CHAT_ID). Сообщения из других групп игнорируются автоматически.
