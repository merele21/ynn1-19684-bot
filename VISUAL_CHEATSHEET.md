## 🎨 Типы конфигураций хештегов

### Тип 1: Простой хештег

```
  #новости
      ↓
  Сообщение с текстом
      ↓
  Пересылка БЕЗ хештега
      ↓
  Группа A, Тред 123
```

**config.json:**
```json
{
  "#новости": {
    "needs_fsm": false,
    "chat_id": -1001234567890,
    "thread_id": 123,
    "delay": 0
  }
}
```

---

### Тип 2: С задержкой (медиагруппы)

```
  #отчёт + [фото 1]
      ↓
  [фото 2] (без хештега)
      ↓
  [фото 3] (без хештега)
      ↓
  ⏳ Ждём 15 секунд
      ↓
  Пересылаем ВСЕ вместе
      ↓
  Группа A, Тред 456
```

**config.json:**
```json
{
  "#отчёт": {
    "needs_fsm": false,
    "chat_id": -1001234567890,
    "thread_id": 456,
    "delay": 15
  }
}
```

---

### Тип 3: С выбором (FSM)

```
     #закрытие
         ↓
   Выбор кнопками:
   [Одиночное] [Медиагруппа]
         ↓              ↓
    Группа A       Группа B
    Тред 100       Тред 200
```

**config.json:**
```json
{
  "#закрытие": {
    "needs_fsm": true,
    "options": {
      "single": {
        "chat_id": -1001234567890,
        "thread_id": 100,
        "delay": 0
      },
      "mediagroup": {
        "chat_id": -1009876543210,
        "thread_id": 200,
        "delay": 15
      }
    }
  }
}
```

## 🛠️ Troubleshooting в картинках

### ❌ Проблема: Бот не пересылает

```
Проверьте:
┌────────────────────────────┐
│ ✓ Хештег добавлен?         │ → /list_hashtags
│ ✓ SOURCE_CHAT_ID правильный?│ → /get_supergroup_id
│ ✓ Бот админ в исходной?    │ → Настройки группы
│ ✓ Бот в целевой группе?    │ → Проверить участников
└────────────────────────────┘
```

### ❌ Проблема: Thread ID не работает

```
Попробуйте:
┌─────────────────────────────────┐
│ 1. Способ через ссылку          │ ← Самый надёжный
│ 2. Упоминание в группе          │
│ 3. Пересылка из топика          │
└─────────────────────────────────┘
```
