# 📚 Примеры использования

## Сценарии использования бота

### 🎯 Сценарий 1: Простая пересылка новостей

**Задача:** Пересылать все сообщения с хештегом `#новости` в отдельный тред.

**Настройка:**
```bash
/add_hashtag #новости -1001234567890 123
```

**Использование:**
```
Пользователь в группе: #новости Вышла новая версия продукта!

Результат: Сообщение "Вышла новая версия продукта!" появится в треде 123
```

---

### 📸 Сценарий 2: Пересылка фотоотчётов с задержкой

**Задача:** Пересылать медиагруппы с 10+ фотографиями, собирая их в течение 15 секунд.

**Настройка:**
```bash
/add_hashtag #отчёт -1001234567890 456 delay=15
```

**Использование:**
```
Пользователь отправляет:
1. #отчёт Отчёт за день [фото 1]
2. [фото 2]
3. [фото 3]
...
11. [фото 11]

Бот ждёт 15 секунд и пересылает ВСЕ фото вместе в тред 456
```

---

### 🔄 Сценарий 3: Пересылка с выбором места назначения (FSM)

**Задача:** По хештегу `#закрытие` пересылать либо в один тред (одно фото), либо в другой (медиагруппа).

**Настройка в config.json:**
```json
{
  "hashtags": {
    "#закрытие": {
      "needs_fsm": true,
      "description": "Закрытие смены",
      "options": {
        "single": {
          "chat_id": -1001234567890,
          "thread_id": 100,
          "delay": 0
        },
        "mediagroup": {
          "chat_id": -1009876543210,
          "thread_id": 200,
          "delay": 15
        }
      }
    }
  }
}
```

**Использование:**
```
Пользователь: #закрытие Смена закрыта

Бот: "Выберите тип пересылки:"
     [📷 Одиночное фото] [🖼 Медиагруппа]

Если выбрано "Одиночное фото":
→ Пересылка в чат -1001234567890, тред 100

Если выбрано "Медиагруппа":
→ Бот ждёт 15 секунд и собирает все фото
→ Пересылка в чат -1009876543210, тред 200
```

## 🛠 Получение ID группы и треда

### Шаг 1: Получить ID группы

1. Отправьте боту команду:
```
/get_supergroup_id
```

2. Перейдите в нужную группу и перешлите любое сообщение боту

3. Бот ответит:
```
📊 Информация о группе:

ID чата: -1001234567890
Название: Моя рабочая группа
```

### Шаг 2: Получить ID треда

1. Отправьте боту команду:
```
/get_thread_id
```

2. Перейдите в нужный тред (топик) и перешлите сообщение боту

3. Бот ответит:
```
📊 Информация о группе:

ID чата: -1001234567890
Название: Моя рабочая группа

📌 ID треда: 123
```

## 💡 Полезные советы

### Совет 1: Тестирование конфигурации

Перед запуском в продакшн, протестируйте на тестовой группе:

1. Создайте тестовую группу с тредами
2. Добавьте бота
3. Настройте хештег для теста
4. Отправьте тестовое сообщение
5. Убедитесь, что всё работает корректно

### Совет 2: Использование описаний

В `config.json` используйте `description` для документирования:

```json
{
  "#отчёт": {
    "description": "Фотоотчёты за смену -> тред 'Отчёты'",
    ...
  }
}
```

Затем используйте `/list_hashtags` для быстрого просмотра.

### Совет 3: Группировка хештегов

Используйте префиксы для группировки:

```
#отчёт_утро → Утренние отчёты
#отчёт_вечер → Вечерние отчёты
#новость_важная → Важные новости
#новость_общая → Общие новости
```

### Совет 4: Задержка для разных типов медиа

- **1-5 фото**: delay=0 (без задержки)
- **6-10 фото**: delay=10
- **11+ фото**: delay=15-20
- **Очень большие медиагруппы**: delay=25

## ⚠️ Частые проблемы и решения

### Проблема: Бот не реагирует на хештег

**Решение:**
1. Проверьте, что хештег добавлен в конфигурацию: `/list_hashtags`
2. Убедитесь, что хештег написан правильно (с #)
3. Проверьте, что сообщение отправлено в исходную группу (SOURCE_CHAT_ID)

### Проблема: Бот не может переслать сообщение

**Решение:**
1. Убедитесь, что бот добавлен в целевую группу
2. Проверьте права бота (должен быть админом в исходной группе)
3. Проверьте правильность chat_id и thread_id

### Проблема: Задержка не работает для медиагрупп

**Решение:**
1. Убедитесь, что параметр `delay` больше 0
2. Проверьте, что последующие фото отправляются БЕЗ хештега
3. Убедитесь, что между фото проходит не больше времени, чем указано в delay

## 🎓 Продвинутые настройки

### Множественные администраторы

В `.env` файле укажите несколько ID через запятую:
```env
ADMIN_IDS=123456789,987654321,456789123
```

### Резервное копирование конфигурации

Перед внесением изменений создавайте резервную копию:
```bash
cp config.json config.json.backup
```

### Мониторинг работы бота

Запускайте бота с перенаправлением логов:
```bash
python bot.py > bot.log 2>&1 &
```

Просмотр логов в реальном времени:
```bash
tail -f bot.log
```

## 🚀 Deployment на сервер

### Вариант 1: systemd service

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Forwarder Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/telegram_forwarder_bot
ExecStart=/usr/bin/python3 /path/to/telegram_forwarder_bot/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Запуск:
```bash
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
```

### Вариант 2: Docker (будущее расширение)

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "bot.py"]
```
