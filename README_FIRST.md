# 👋 Начните отсюда!

## 🎉 Поздравляем! Вы получили Telegram Forwarder Bot

Этот бот автоматически пересылает сообщения из одной группы в другую по хештегам.

---

## ⚡ Быстрый старт (5 минут)

### 1️⃣ Распакуйте архив
```bash
tar -xzf telegram_forwarder_bot.tar.gz
cd telegram_forwarder_bot
```

### 2️⃣ Установите зависимости
```bash
pip install -r requirements.txt
```

### 3️⃣ Настройте бота
```bash
# Создайте .env файл
cp .env.example .env

# Отредактируйте .env
nano .env  # или используйте любой редактор
```

**Что нужно заполнить в .env:**
- `BOT_TOKEN` - получите у [@BotFather](https://t.me/BotFather)
- `SOURCE_CHAT_ID` - оставьте временное значение, получим позже
- `ADMIN_IDS` - ваш Telegram ID (получите у [@userinfobot](https://t.me/userinfobot))

### 4️⃣ Запустите бота
```bash
./run.sh
# или просто: python bot.py
```

### 5️⃣ Получите ID группы
1. Откройте бота в Telegram
2. Отправьте `/get_supergroup_id`
3. Перешлите боту любое сообщение из вашей группы
4. Скопируйте полученный ID в `.env` как `SOURCE_CHAT_ID`
5. Перезапустите бота

### 6️⃣ Настройте первый хештег
```bash
# В чате сботом:
/add_hashtag #тест -1001234567890 123

# Где:
# #тест - ваш хештег
# -1001234567890 - ID целевой группы (получите через /get_supergroup_id)
# 123 - ID треда (получите через /get_thread_id)
```

### 7️⃣ Протестируйте!
Отправьте в исходную группу:
```
#тест Привет, мир!
```

Должно появиться в целевом треде:
```
Привет, мир!
```
(без хештега)

## 🎯 Основные возможности

✅ **Пересылка по хештегам** - Настройте хештег = определите место пересылки

✅ **Whitelist** - Только настроенные хештеги обрабатываются

✅ **FSM режим** - Выбор между "одиночное фото" и "медиагруппа"

✅ **Задержка (delay)** - Для сбора медиагрупп с 11+ фотографиями

✅ **Команды управления** - Добавляйте/удаляйте хештеги через бота

✅ **Удаление хештегов** - Хештег автоматически удаляется при пересылке

## 🔑 Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Показать список команд |
| `/add_hashtag` | Добавить новый хештег |
| `/list_hashtags` | Список всех хештегов |
| `/remove_hashtag` | Удалить хештег |
| `/get_supergroup_id` | Получить ID группы |
| `/get_thread_id` | Получить ID треда |

## 🆘 Проблемы?

### Бот не запускается
```bash
# Проверьте установку зависимостей
pip install -r requirements.txt

# Проверьте .env файл
cat .env
```

### Сообщения не пересылаются
1. ✅ Хештег добавлен? → `/list_hashtags`
2. ✅ SOURCE_CHAT_ID правильный?
3. ✅ Бот админ в исходной группе?
4. ✅ Бот добавлен в целевую группу?

## 🌟 Особенности

### Простые хештеги
```json
{
  "#новости": {
    "chat_id": -1001234567890,
    "thread_id": 123,
    "delay": 0
  }
}
```

### FSM хештеги (с выбором)
```json
{
  "#закрытие": {
    "needs_fsm": true,
    "options": {
      "single": { "chat_id": -100123, "thread_id": 1 },
      "mediagroup": { "chat_id": -100456, "thread_id": 2, "delay": 15 }
    }
  }
}
```

### Хештеги с задержкой (медиагруппы)
```json
{
  "#отчёт": {
    "chat_id": -1001234567890,
    "thread_id": 456,
    "delay": 15
  }
}
```
