## [1.1.0] - 2025-02-18 (Feature Release)

### ✨ Добавлено

#### Нативное получение Thread ID
- **`/get_thread_id` работает напрямую в чатах** - больше не нужна пересылка!
- **Мгновенное получение Chat ID + Thread ID** - одна команда в нужном месте
- **100% надёжность** - thread_id всегда доступен при вызове в топике
- **Простота использования** - 1 команда вместо 3 шагов

### 🗑️ Удалено

- **Команда `/get_supergroup_id`** - объединена с `/get_thread_id`
- **Обработчик `handle_forwarded_message`** - больше не нужен
- **Все костыли с пересылкой** - заменены нативным API

### 🔧 Изменено

- **Команда `/get_thread_id`** - полностью переписана
  - Теперь показывает информацию о текущем чате
  - Работает в топиках, группах, личных чатах
  - Возвращает готовую команду для настройки хештега

- **Команда `/help`** - обновлена справка
  - Новое описание `/get_thread_id`
  - Акцент на нативный метод

### 📚 Документация

- **RELEASE_v1.1.0.md** - полное описание релиза
- Обновлён CHANGELOG.md

### ⚡ Производительность

- **Удалена обработка пересланных сообщений** - снижение нагрузки
- **Прямое использование Telegram API** - быстрее и надёжнее

### 🎯 Использование

**Раньше:**
```
Бот в личке: /get_thread_id
→ Пересылка сообщения
→ Надежда на результат
```

**Теперь:**
```
В топике: /get_thread_id
→ Мгновенный результат!
```

## [1.0.3] - 2025-02-18 (Финальная стабильная версия)

### 🐛 Исправлено (Критическое)

#### Полностью устранена проблема "сталкеринга"
- **Удалён обработчик `handle_mention_in_group`** полностью - корень всех проблем
- **Бот больше НЕ обрабатывает каждое сообщение** - только команды и пересылки
- **Восстановлена нормальная работа** - никаких ложных срабатываний

### 🗑️ Удалено (Намеренно)

- **Полностью удалён обработчик упоминаний бота в группах**
  - Причина: технически невозможно реализовать без перехвата всех сообщений
  - Блокировал основной функционал (пересылку хештегов)
  - Создавал огромную нагрузку на бота

### 🔧 Изменено

- **Команда `/get_thread_id`** - обновлены инструкции
  - Убрано упоминание о несуществующем способе с @bot
  - Акцент на ручной способ (через ссылку) как самый надёжный
  - Детальные инструкции по разбору ссылки

- **Команда `/help`** - упрощена справка
  - Только два надёжных способа
  - Подробное объяснение ручного метода

### 📚 Документация

- **FIXES_v1.0.3.md** - финальное описание исправлений
- Обновлён CHANGELOG.md

### ⚡ Производительность

- **Снижение нагрузки на ~95%** - больше не проверяем каждое сообщение
- **Мгновенная обработка хештегов** - никаких помех от других обработчиков

### 🎯 Рекомендации

**Лучший способ получения Thread ID:**
```
1. Скопировать ссылку на первое сообщение треда
2. t.me/c/1234567890/12345
   → Chat ID: -1001234567890
   → Thread ID: 12345
3. Работает всегда на 100%!
```

## [1.0.0] - 2025-02-18

### ✨ Добавлено

#### Основной функционал
- 🤖 Базовая структура бота на aiogram 3.4.1
- 📤 Пересылка сообщений по хештегам
- 🏷️ Автоматическое удаление хештегов при пересылке
- 📋 Whitelist хештегов (только настроенные хештеги обрабатываются)

#### Система FSM
- 🔄 FSM для хештегов с несколькими вариантами пересылки
- 🖼️ Выбор между "одиночное фото" и "медиагруппа"
- ⚙️ Настраиваемые опции для каждого типа пересылки

#### Задержка для медиагрупп
- ⏰ Настраиваемая задержка (delay) для сбора сообщений
- 📸 Автоматический сбор медиагрупп с 11+ фотографиями
- 🔗 Объединение последовательных сообщений без хештега

#### Команды администратора
- `/start` - Приветствие и список команд
- `/help` - Подробная справка
- `/add_hashtag` - Добавление нового хештега
- `/list_hashtags` - Просмотр всех настроенных хештегов
- `/remove_hashtag` - Удаление хештега
- `/get_supergroup_id` - Получение ID группы
- `/get_thread_id` - Получение ID треда

#### Конфигурация
- 📄 JSON конфигурация для хештегов
- 🔐 .env файл для чувствительных данных
- 👥 Поддержка нескольких администраторов
- 💾 Автоматическое сохранение изменений

#### Документация
- 📖 Подробный README.md
- 📚 Примеры использования (USAGE_EXAMPLES.md)
- ❓ FAQ с частыми вопросами
- 🚀 Скрипт быстрого запуска (run.sh)

#### Безопасность
- 🔒 Проверка прав администратора для всех команд
- 🛡️ Whitelist хештегов
- 🎯 Работа только в указанной исходной группе

### 🛠️ Технические детали

#### Структура проекта
```
telegram_forwarder_bot/
├── bot.py                 # Главный файл
├── config.py              # Управление конфигурацией
├── config.json            # Конфигурация хештегов
├── handlers/
│   ├── admin.py           # Админские команды
│   ├── forwarding.py      # Логика пересылки
│   └── fsm.py             # FSM обработчики
└── utils/
    └── hashtag_parser.py  # Утилиты для хештегов
```

#### Зависимости
- aiogram==3.4.1
- python-dotenv==1.0.0
- aiofiles==23.2.1

#### Особенности реализации
- Асинхронная архитектура
- Роутеры для модульности
- FSM хранилище в памяти (MemoryStorage)
- Логирование с уровнем INFO
